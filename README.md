## 📌 Аннотация и научная мотивация

Обнаружение объектов в условиях экстремально низкой освещенности (ночное наблюдение, беспилотный транспорт, автономные роботы) сталкивается с **«парадоксом улучшения» (Enhancement Paradox)**:

1. **Недостатки попиксельного улучшения (LLIE-моделей)**:  
   Классические методы предварительного осветления изображений (RetinexNet, Zero-DCE, KinD, EnlightenGAN) восстанавливают пиксели, но неизбежно **усиливают сенсорный шум матрицы, размывают контрастные границы объектов и порождают цветовые артефакты**. Кроме того, они создают неприемлемую вычислительную задержку (>40–60 мс), делая обработку в реальном времени невозможной.
2. **Ограничения стандартных детекторов на темных сценах**:  
   Прямое обучение сверточных сетей (таких как YOLOv8s) на низкоконтрастных темных кадрах приводит к деградации признаков из-за низкого соотношения сигнал/шум (SNR). Стандартная метрика IoU / CIoU становится нестабильной: малейшее смещение рамки малоконтрастного объекта на 1–2 пикселя приводит к обнулению перекрытия.

### 💡 Концепция RI-YOLO

**RI-YOLO (Retinex-Informed YOLO)** полностью исключает шаг попиксельного восстановления кадра и переносит принципы декомпозиции Retinex непосредственно в глубокое латентное пространство нейросети:

- **Spatial Retinex Feature Decoupling (RFDBlock)**: Выполняет декомпозицию признаков в backbone детектора на уровне $P_5$ (после SPPF). Модуль оценивает пространственную карту освещенности $L$ и выделяет структуру объектов $S$, масштабируемую обучаемым гейтом $\gamma$.
- **Retinex Smoothness Loss (RSL)**: Накладывает регуляризацию по полной вариации (TV-loss) на карту $L$, обеспечивая кусочно-гладкое распределение и подавляя высокочастотный сенсорный шум.
- **Normalized Wasserstein Distance (NWD)**: Моделирует рамки в виде 2D-гауссиан с физически откалиброванной по датасету константой масштаба, обеспечивая непрерывный градиент даже при нулевом пересечении IoU.

- [x] **Аудит обученных чекпойнтов (CP-0.3)**: Зафиксирована устойчивая динамика обучаемого гейта $\gamma \in [+0.002, +0.018]$ без риска вырождения.

## 🔬 Математический аппарат метода

### 1. Модуль Spatial Retinex Feature Decoupling (RFDBlock)

Для тензора признаков $x \in \mathbb{R}^{B \times C \times H \times W}$ на выходе SPPF выполняется адаптивная декомпозиция:

$$
\begin{aligned}
f &= \mathrm{Conv}_{1\times1}(x) \\
L(u, v) &= \sigma(\mathrm{Conv}_{1\times1}(f)) \quad \in [0, 1]^{B \times 1 \times H \times W} \\
S &= \mathrm{Conv}_{3\times3}(f \odot (1.0 - L)) \\
y &= x + \gamma \cdot S
\end{aligned}
$$

- $\gamma \in \mathbb{R}$ — обучаемый скаляр с инициализацией $\gamma = 0$ (тождественный старт).
- $L$ выполняет функцию селективного подавления затемненных и зашумленных областей.
- $S$ выделяет высокочастотные структурные границы объектов.

### 2. Функция потерь Retinex Smoothness Loss (RSL)

Для предотвращения резких скачков карты освещенности накладывается регуляризатор Total Variation (TV-loss) с нормировкой на число пространственных элементов:

$$
\mathcal{L}_{\text{RSL}} = \frac{1}{B \cdot H \cdot W} \sum_{b=1}^{B} \left( \sum_{h, w} |L_{b,1,h+1,w} - L_{b,1,h,w}| + \sum_{h, w} |L_{b,1,h,w+1} - L_{b,1,h,w}| \right)
$$

Итоговая функция потерь детектора:

$$
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{det}} + \lambda_{\text{tv}} \cdot \mathcal{L}_{\text{RSL}}, \quad \text{где } \lambda_{\text{tv}} = 0.001
$$

### 3. Метрика рамок Normalized Wasserstein Distance (NWD)

Ограничивающие рамки аппроксимируются двумерными гауссианами $\mathcal{N}(\mu, \Sigma)$. Расстояние Вассерштейна 2-го порядка выражается аналитически:

$$
W_2^2(\mathcal{N}_1, \mathcal{N}_2) = \|\mu_1 - \mu_2\|_2^2 + \frac{(w_1 - w_2)^2 + (h_1 - h_2)^2}{4}
$$

Нормализованная метрика:

$$
\mathrm{NWD} = \exp\left( -\frac{\sqrt{W_2^2 + \epsilon^2}}{C_{rec}} \right)
$$

- $C_{rec} = 10.24$ — константа масштаба, физически привязанная к шагу признаков P4-stride датасета ExDark.
- В режиме **`sizegate`** вес метрики плавно затухает для крупных объектов:  
  $\alpha(s) = \alpha_0 \cdot \exp\left(-\frac{s}{\tau_{size}}\right)$, где $s = \sqrt{w \cdot h}$, $\alpha_0 = 0.2$, $\tau_{size} = 5.12$.

## 📊 Текущие экспериментальные результаты

> **Важное замечание о воспроизводимости**:  
> На датасете **ExDark** (12 классов, экстремальная темнота) стандартный предобученный детектор **YOLOv8s** при 100 эпохах обучения достигает честного уровня **$\approx 0.696$ mAP@50**. Все сравнения в данном проекте проводятся относительно этого строгого бейслайна в равных условиях без спекулятивных занижений.

### Аппаратный профиль на NVIDIA GeForce RTX 3070 Ti (8 GB VRAM)

Данные получены скриптом `scripts/bench.py` на зафиксированном стенде (PyTorch 2.5.1, CUDA 12.1):

| Архитектура | Параметры | GFLOPs | Режим (BS, Prec) | Задержка p50 (мс) | Задержка p95 (мс) | Пропускная способность |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| **YOLOv8s (Baseline)** | 11.17M | 28.81 | BS=1, FP32 | **4.92 мс** | 6.93 мс | 203.2 FPS |
| **YOLOv8s (Baseline)** | 11.17M | 28.81 | BS=16, FP16 | **32.91 мс** | 34.19 мс | 486.2 FPS |
| **RI-YOLO (pos-postsppf)** | 13.79M | 30.91 | BS=1, FP32 | **5.15 мс** | 6.12 мс | 194.4 FPS |
| **RI-YOLO (pos-postsppf)** | 13.79M | 30.91 | BS=16, FP16 | **32.41 мс** | 32.65 мс | **493.7 FPS** |
| **RI-YOLO (capctrl)** | 13.79M | 30.91 | BS=16, FP16 | **32.38 мс** | 32.62 мс | **494.2 FPS** |

*Накладные расходы модуля RFD составляют всего $+0.23$ мс (+4.6%), сохраняя частоту кадров выше 190 FPS при одиночных запросах и свыше 490 FPS в пакетном режиме.*

## 🛠️ Установка и быстрый старт

### 1. Клонирование и виртуальное окружение

```bash
git clone https://github.com/Mr-Flyguy/ri-yolo.git
cd ri-yolo

# Создание виртуального окружения
python -m venv .venv

# Активация окружения (Windows PowerShell)
.\.venv\Scripts\Activate.ps1
# Или Linux / macOS:
# source .venv/bin/activate

# Установка пакета в режиме разработки
pip install -e .
```

### 2. Подготовка датасета ExDark

Структура каталога `datasets/ExDark`:

```text
datasets/
└── ExDark/
    ├── images/
    │   ├── train/          # 3000 обучающих изображений
    │   └── val/            # 1800 валидационных изображений
    └── labels/
        ├── train/          # YOLO-формат: <class> <x> <y> <w> <h>
        └── val/
```

Конфигурационный файл `exdark.yaml` находится в корне репозитория.

## 🚀 Воспроизведение экспериментов

Все эксперименты запускаются через единый стандартизированный CLI-оркестратор:

```bash
# Запуск всей серии E3' (исследование глубины встраивания, 5 моделей по 100 эпох):
python scripts/train_phase1.py --run e3 --data exdark.yaml --device 0 --epochs 100

# Запуск отдельной конфигурации (например, канонический post-SPPF):
python scripts/train_phase1.py --run e3p__pos-postsppf__s0 --data exdark.yaml --device 0 --epochs 100

# Аппаратный бенчмарк инференса на локальном GPU:
python scripts/bench.py --batches 1 16 --half 0 1 --out artifacts/phase0/bench_local.csv

# Анализ пространственной корреляции карты Retinex с яркостью:
python scripts/corr_LY.py --ckpt runs/e3p__pos-postsppf__s0/weights/best.pt --images exdark.yaml
```
