**Illumination Map ($L$) Diagnostic Methodology:**
To rigorously evaluate whether the latent illumination map $L(x,y)$ physically tracks scene illumination, the model is evaluated in strict deterministic evaluation mode (`eval()`) with frozen BatchNorm statistics. The map $L$ is captured via a forward hook directly on the `ill_estimator` sub-module output (`Conv2d(512, 1, 1, bias=False)` followed by `Sigmoid()`), yielding a spatial map of size $20 \times 20$ at $640 \times 640$ input resolution. Physical scene luminance $Y$ is measured via standard Rec.601 luma ($Y = 0.299R + 0.587G + 0.114B$), HSV Value $V$, and logarithmic luma $\log(Y + 10^{-4})$. Image brightness is downsampled to the $20 \times 20$ feature resolution using area-based average pooling (`cv2.INTER_AREA`) and bilinear interpolation (`cv2.INTER_LINEAR`). Diagnostics are evaluated both across a deterministic 300-image sample (`diag_image_list.txt`) and across the full validation split ($N=1765$). Both per-frame correlation metrics (mean $\pm$ SD, 95% CI) and pooled pixel correlations are reported, along with spatial dispersion ($L_{\text{std}}$), map mean ($L_{\text{mean}}$), and saturation fraction ($L \ge 0.95$).
